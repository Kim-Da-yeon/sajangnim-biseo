# 규칙과 온톨로지 정리

이 문서는 무엇을 규칙으로 정하고 무엇을 LLM에 맡기는지 정리한다. 판단 순서는 규칙 → 사장님 답변·설명 → LLM 조건 판단 → LLM 최종 판단이다. 최종 판단은 규칙이 일치를 낸 공고와 사용자가 요청한 공고에 쓴다. 최종 상태는 규칙이 아니라 이 단계가 정한다.

## 1. 누가 판단하나

| 대상 | 판단 주체 | 근거 |
|---|---|---|
| 숫자 비교(근로자 수, 매출, 금리 등) | 규칙 | 조건 값과 입력값 대조 |
| 날짜 비교, 신청기간 상태 | 규칙 | 공고 기간과 기준일 |
| 소상공인·소공인 해당 | 규칙 + 온톨로지 | 업종별 근로자·매출 기준 |
| 제외 업종 | 규칙 + 온톨로지 | 정책자금 제외 목록, 예외 |
| 지역 일치 | 규칙 | 시군구 표기 비교 |
| 임대차 기간 계산 | 규칙 + 온톨로지 | 상가임대차법 조문 |
| 규칙으로 표현 못 한 조건 | 사장님 답변 → 진술 대조 LLM | 설명 문구 인용 필수 |
| 그래도 남은 애매한 조건 | 조건 판단 LLM | 공고 문구 인용 필수, 화면에 표시 |
| 최종 상태 | 최종 판단 LLM | 공고 전체, 입력값, 규칙·온톨로지 결과를 읽고 결정. 근거 문구 코드 대조, 없으면 확인 필요 |
| 기관 재량 조항 | 판단 안 함 | 합산 제외, 항상 표시 |
| 공고 안의 표기 충돌 | 판단 안 함 | 확인 필요 |

## 2. 판정 규칙

| 번호 | 규칙 | 코드 |
|---|---|---|
| R1 | 조건 결과는 일치, 불일치, 확인 필요, 기관 판단 중 하나 | `check_condition` |
| R2 | 입력값이 없으면 확인 필요 | `check_condition` |
| R3 | 조건을 어겨도 예외 단서가 있고 해당 여부를 모르면 확인 필요 | `check_condition` |
| R4 | OR 그룹: 하나라도 일치면 일치, 전부 불일치면 불일치, 나머지는 확인 필요 | `judge` |
| R5 | 공고 상태: 불일치가 하나라도 있으면 불일치, 없고 확인 필요가 있으면 확인 필요, 나머지는 일치 | `judge` |
| R6 | 기관 재량 조항은 합산에서 빼고 표시 | `judge` |
| R7 | 공고 표기 충돌 조건: 값이 맞으면 확인 필요, 어기면 불일치 | `check_condition` |
| R8 | 지원 분야는 상위·하위 분류가 섞이므로 표기가 달라도 불일치로 단정하지 않음 | `text_state` |
| R9 | 앞선 모집에 신청하지 않았으면 선정도 아님 | `field_value` |
| R10 | 기간: 시작 전 접수 전, 끝난 뒤 마감, 끝 없음은 일정 확인 필요. 마감일 당일은 기간 내 | `period_status` |
| R11 | 연 환산 매출: 2024년 이전 개업은 신고 매출, 2025년 개업은 월평균×12 | `annualized_revenue` |

코드 위치: `src/judge_20261102_v6.py`

## 4. LLM 답을 코드로 막는 장치

| 장치 | 내용 |
|---|---|
| 인용 확인 | 추출, 검증 지적, 진술 대조, 조건 판단, 돈 항목의 근거 문구가 원문에 없으면 폐기 또는 미확인 표시 |
| lint | 기간 누락, 빈 값, 잘못된 파생 조건, 중복 조건은 재추출 |
| 금지 표현 | "자격이 있습니다", "선정됩니다", "받을 수 있습니다", "법적으로", "권리가 있습니다" 출력 차단 |
| 목록 제외 | 자격 조건을 3개 미만으로 추출한 공고는 화면에서 제외 |

## 5. 임대차·법령의 범위

- 하는 일: 계약서의 날짜와 금액을 옮겨 적기, 조문 기간을 날짜에 대입, 조문 원문 표시
- 하지 않는 일: 계약서 유불리 검토, 개별 사건의 권리 유무 판단, 분쟁 대응 조언, 서류 대리 작성
- 조문 기준일: 2026-11-02 수집본. 시행일 이후 개정은 다시 수집해야 함

## 6. 알려진 한계

- 최종 판단은 결론을 못 내고 확인 필요로 답하는 경향이 있다(4차 오답 6건 중 5건)
- 규칙 대조만 쓴 화면에서 "일치"가 아닌 공고는 최종 판단을 누르기 전까지 규칙 결과다
- OR 안의 AND 조건은 스키마로 표현하지 못한다
- 재보증 제한 업종 목록은 온톨로지에 없다
- 과밀억제권역 지역 구분은 주소만으로 정하지 않고 확인 필요로 둔다
